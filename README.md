# Java File Handling

## 📌 Project Description

This is a simple Java File Handling project developed using Eclipse IDE.  
The project demonstrates basic file operations in Java such as creating, writing, reading, appending, and copying files.

## ✨ Features

- Create a new text file
- Write data into a file
- Read data from a file
- Append new data to an existing file
- Copy data from one file to another
- Handle file-related exceptions using `IOException`

## 🛠 Technologies Used

- Java
- Eclipse IDE
- Java I/O (`java.io`)
- Scanner

## ▶️ How to Run

1. Open Eclipse IDE.
2. Import or open the project.
3. Open `FileHandling.java`.
4. Right-click on the Java file.
5. Select **Run As → Java Application**.
6. Check the output in the Eclipse Console.

## 💻 File Operations

The program performs the following operations:

1. Creates `student.txt`.
2. Writes student information into the file.
3. Reads and displays the file content.
4. Appends additional information to the file.
5. Creates a copy named `student_copy.txt`.
